Run a check

Your browser asks several Cloudflare addresses which data centre answered, timing each one 5 times. It takes a few seconds. Run it again on another network, such as mobile data, a VPN or another ISP, to compare.

Add Cloudflare-hosted sites (optional)

Most sites don't let other pages read their trace, so these often show "No readable answer". The built-in addresses always work where Cloudflare allows it.

Result

Saved runs

Map the data centres serving IPv4 and IPv6 and keep a history of location changes.

What leaves your browser. The check makes ordinary HTTPS requests from your browser to Cloudflare's diagnostic page (/cdn-cgi/trace) on the addresses listed, plus any sites you add. Cloudflare sees your IP address, as it does for any site it serves. Nothing is sent to coolcode.ca. Your full IP address is shown on screen but never saved. Saved runs keep only the network prefix (/24 or /48), and only in this browser, under coolcode:colocheck:runs. Data-centre names come from Cloudflare's published location list.
